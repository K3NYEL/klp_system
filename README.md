# KLP SYSTEM (Aun en desarrollo)

Sistema de gestión y facturación desarrollado para administrar operaciones comerciales desde una aplicación de escritorio.

KLP SYSTEM está diseñado para ejecutarse de forma local en Linux y Windows, con soporte para generación de ejecutables mediante PyInstaller.

---

## Características

- Gestión de operaciones de facturación.
- Aplicación de escritorio.
- Ejecución local mediante entorno virtual de Python.
- Pruebas automatizadas de infraestructura.
- Generación de ejecutables independientes.
- Soporte de compilación para Linux y Windows.
- Arquitectura preparada para futuras ampliaciones.

## Requisitos

Para ejecutar el proyecto desde el código fuente necesitas:

- Python 3
- `pip`
- Entorno virtual de Python
- Dependencias definidas en `requirements.txt`
