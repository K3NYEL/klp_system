# KLP SYSTEM

**Sistema de gestión y facturación de escritorio desarrollado en Python.**

KLP SYSTEM es una aplicación de escritorio diseñada para facilitar la gestión de operaciones comerciales desde una interfaz moderna, sencilla y organizada.

Permite administrar diferentes áreas del negocio desde un mismo sistema, utilizando almacenamiento local y una interfaz desarrollada con **Tkinter + ttk**.

## Funciones

* **Facturación** — Creación y gestión de facturas.
* **Inventario** — Administración y control de productos.
* **Clientes** — Gestión de información de clientes.
* **Caja** — Control de efectivo, ingresos, gastos y movimientos.
* **Dashboard** — Resumen de información importante del sistema.
* **Autenticación** — Inicio de sesión y gestión de usuarios.
* **Reportes** — Generación de documentos PDF.
* **Auditoría** — Registro de operaciones importantes realizadas en el sistema.
* **Almacenamiento local** — Base de datos SQLite para la información de la aplicación.
